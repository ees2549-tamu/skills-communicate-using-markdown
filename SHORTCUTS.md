# Markdown Shortcuts

The following are useful shortcuts when working in the GitHub Markdown editor:

- Use `Ctrl + V` with a copied link onto a line to change it into a link.
- `Ctrl + E`: Turns a regular line into a `code line`.
- `Ctrl + Shift + 7`: Turns a highlighted selection into a numbered list.
- `Ctrl + Shift + 8`: Turns a highlighted selection into a bulleted list.
